# Anny
A game about something, it’s just you and the game.
This is a very simplistic low poly game, there's not too much to it.

## For now you can:
1. Ride the cars, click to ride, click to get off.
2. Grab and throw items (cans and apples) with left and right click respectively.
3. Wait for the bus at the bus stop, get on the bus and reach an isolated island.
4. Talk with the NPCs, the is a secret code but it might take a lot of time to discover.
